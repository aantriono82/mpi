# MPI Matematika SMP — Kelas 7 (v1)

Media Pembelajaran Interaktif untuk Matematika SMP Kelas 7, Kurikulum Merdeka, pendekatan Pembelajaran Mendalam.

## Isi v1
- Beranda dan daftar Kelas 7
- 9 halaman MPI: Bilangan Bulat, Bilangan Rasional, Aritmetika Sosial, Perbandingan, Bentuk Aljabar, Garis dan Sudut, Kesebangunan, Kekongruenan, Data dan Diagram
- Halaman TP & ATP Kelas 7 (tabel + PDF asli di `dokumen/`)
- Setiap MPI: masalah kontekstual, simulasi manipulatif, kuis 10 soal dengan pembahasan setelah menjawab, dan refleksi penutup. Skor hanya ada di halaman dan hilang saat halaman ditutup.

## Menjalankan secara lokal
Buka `index.html` di peramban, atau jalankan server statis dari folder ini, misalnya `python3 -m http.server 8000`, lalu buka `http://localhost:8000/`.

## GitHub Pages
Situs ini statis tanpa proses build. Setelah di-push ke repo `aantriono82/mpi` (branch main, folder root), aktifkan Pages di Settings > Pages > Deploy from a branch, lalu verifikasi di https://aantriono82.github.io/mpi/

## Sumber
TP dan ATP: MGMP Matematika SMP Kabupaten Lampung Tengah, Tahun Pelajaran 2026/2027, Fase D (`dokumen/ATP_Matematika_Fase_D_MGMP.pdf`).
